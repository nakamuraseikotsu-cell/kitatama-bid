# 北多摩 公共工事 入札情報

北多摩17市の工事公告を毎朝更新し、最低制限価格の目安と自社の技術者の配置チェックができる無料ツールの画面です。

- 画面：https://nyusatsu.ma-ko-to-jp.com/
- データ：Google Apps Script とスプレッドシート（案件情報は中小企業庁「官公需情報ポータルサイト」の検索APIで取得）
- 運営：株式会社誠

`index.html` は Apps Script 側の `index.html` と同じファイルです。GitHub Pages で開いたときは、Cookie を送らずに Apps Script へ問い合わせるため、見る人の Google のログイン状態に左右されません。
